## Source handling

1. Never copy Drive folders wholesale.
2. Review every source for personal data, secrets, internal architecture, contracts and third-party content.
3. Store only explicitly approved originals in `portfolio-sources/approved/`.
4. Store optimized public media in `assets/projects/<slug>/` with descriptive names and alt text.
5. Label prototypes as design work and keep them distinct from implemented functionality.
